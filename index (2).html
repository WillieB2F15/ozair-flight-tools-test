Update & Data Transfer

Installed application: v0.31a (pilot evaluation release)

This offline HTML file cannot install or download software updates by itself. An administrator distributes a replacement HTML file. Use the steps below to carry your current working trip and reference records between versions or browsers.

Before replacing the HTML file

1. Save any important trips individually using Save Trip. 2. Select Export Transfer Backup below and keep the downloaded JSON file. 3. Open the newer HTML file, return here, and choose Import Transfer Backup. 4. Verify aircraft, pilots, methods, and trip values before use.

Important limitations

The transfer backup contains the current working trip and aircraft, fueling methods, and pilot contacts. It does not collect previously downloaded trip JSON files, browser history, or other files. Keep individual trip files separately. Import replaces the current working trip and reference lists after your confirmation. No data is sent over the internet. Keep backups secure because they contain pilot contact information.
